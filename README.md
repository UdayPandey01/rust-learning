# My Rust Learning Journey 🚀

## Introduction

This repository documents my comprehensive, hands-on study of the Rust programming language. It contains the code for all the exercises, assessments, and mini-projects I completed as part of a structured, mentor-led curriculum.

The code here represents my real-time learning process, from initial concepts to final, idiomatic solutions. While this repository showcases my dedication and learning velocity, my polished portfolio work can be found in the pinned repositories on my main GitHub profile.

---

## Topics Covered ✅

This journey has taken me from the fundamentals of the language to advanced systems programming and application development. The key topics mastered include:

### Milestone 1: Rust Fundamentals
* **Core Language:** Ownership, Borrowing, and Lifetimes
* **Data Structures:** Structs, Enums, and Collections (`Vec`, `String`, `HashMap`)
* **Control Flow:** Pattern Matching with `match` and `if let`
* **Abstractions:** Traits, Generics, Closures, and Iterators
* **Safety & Robustness:** Comprehensive Error Handling with `Result` and `Option`

### Milestone 2: Intermediate Rust & Systems Programming
* **Data Handling:** `Serde` for professional JSON serialization/deserialization.
* **Concurrency:** Parallelism with Threads & Channels, and I/O-bound concurrency with `async/await` and `tokio`.
* **Low-Level Programming:** `unsafe` Rust and interfacing with C libraries (FFI).
* **Metaprogramming:** Understanding and writing declarative macros.
* **Performance:** Benchmarking with `criterion` and the philosophy of zero-cost abstractions.

### Milestone 3: Advanced Applications
* **Networking:** Building asynchronous clients with `reqwest` for REST APIs.
* **Databases:** Interacting with SQL databases using `sqlx` with compile-time checked queries.
* **Constrained Environments:** Understanding and writing `#[no_std]` code, a prerequisite for blockchain (Solana) and embedded development.
